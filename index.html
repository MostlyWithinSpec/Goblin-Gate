Goblin Gate packages

Signed APT repository for Goblin Gate. Installed boxes use it automatically (System → Updates); you only need this page to add it by hand.

Channels: stable, beta (pre-releases), nightly.

curl -fsSL https://mostlywithinspec.github.io/Goblin-Gate/apt/goblin-gate-archive.gpg \
  | sudo tee /usr/share/keyrings/goblin-gate-archive.gpg >/dev/null
printf 'Types: deb\nURIs: https://mostlywithinspec.github.io/Goblin-Gate/apt\nSuites: beta\nComponents: main\nSigned-By: /usr/share/keyrings/goblin-gate-archive.gpg\n' \
  | sudo tee /etc/apt/sources.list.d/goblin-gate.sources
