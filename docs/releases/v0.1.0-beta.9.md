Fixes from the first days on beta.8, and another round of hardening.

## Fixed

- **Plugins update with Goblin Gate.** The updater only ever updated Goblin Gate itself, so first-party
  plugins (Goblin Sentry) stayed at the version first installed. They now update and roll back together
  with it, and a box where only a plugin is behind is offered the update (System → Updates lists it).
- **Bandwidth by interface** no longer shows traffic under "none": traffic seen by the IPS now gets the
  interface whose network it came from.
- **WAN status** works on a single-WAN box: it shows the WAN's link, address and the gateway it uses,
  instead of "no gateways are configured".
- **Policy hit leaderboard** shows each policy's name next to its number.

## New

- **Restart from the web UI:** your name at the top right is now a menu with *Log out* and *Restart Goblin
  Gate…*, which asks before it restarts (admins only).

## Security

- Updated Go dependencies (`golang.org/x/net`, `golang.org/x/crypto`): a vulnerability scan of this release
  finds no known issues.
- Tighter limits on what a stored password hash may cost to check.
- Stricter checks on static file paths, event stream names, custom rule strings and the Tailscale login
  link.

## Upgrading

Boxes on the beta channel see this version within 6 hours (System → Updates, or `apt-get update && apt-get
install goblin-gate goblin-gate-plugin-sentry` as root). Updating needs no reboot.

## Try it without installing

```
docker run --rm -p 127.0.0.1:8090:8090 ghcr.io/mostlywithinspec/goblin-gate-demo
```

Then open http://localhost:8090.

## Install

Download `goblin-gate-0.1.0-beta.9-amd64.iso` below, boot it (BIOS or UEFI, Secure Boot works), pick the
disk, and open `https://<LAN address>` to run the setup wizard.
