The first beta towards 0.2.0: a reverse proxy with Let's Encrypt, a Home Assistant plugin, a translatable web
UI, a throughput test and an OpenAPI description of the API.

This is a beta. Boxes on the stable channel stay on 0.1.0; pick **beta** under System → Updates to try it.

## New

- **Reverse proxy** (Network → Reverse Proxy): publish web services from your network on public hostnames,
  such as `https://media.example.com` for your Jellyfin, with Let's Encrypt certificates that renew by
  themselves. One rule per hostname, no port forward per service. It runs Caddy under a throwaway system user
  with no privileges. See the wiki page *Reverse Proxy*.
- **Home Assistant plugin** (`goblin-gate-plugin-homeassistant`): the gate shows up in Home Assistant through
  MQTT discovery, with no custom component. You get WAN and gateway sensors, CPU, memory, sessions and boot
  time, a presence tracker for each device you pick, and switches for the firewall policies you allow (for
  example, turning guest Wi-Fi internet on and off). Each switch is a commit you can see and roll back
  under Revisions. See the wiki page *Home Assistant*.
- **Plugin secrets and policy switches:** a plugin can now ask for a password or token. It is stored like
  every other secret: never shown again, and kept when you save the form with the field empty. Plugins
  that need it can get two new capabilities: `devices:read` (the device inventory) and `policies:toggle`
  (switch on and off only the policies you tick). Policy switches are limited to 60 an hour and audited.
- **Throughput test** (Diagnostics): measure the speed between a computer and the box with iperf3. The
  box starts a server on one LAN-side network only, for the length of the test.
- **Network cards** (Diagnostics): each interface's driver, link speed, duplex, queues and offloads, with
  warnings for the usual causes of a slow link. You can override offloads per interface under Network →
  Interfaces → *Network card offloads (advanced)*.
- **OpenAPI:** the API describes itself at `/api/v1/openapi.json`. The description is generated from the
  same route table goblind serves, so it can't drift.
- **Translatable web UI:** every page now gets its text from one catalog (`web/src/i18n/locales/en.json`),
  and each admin's language is stored on the box. English is the only language so far, and translations
  are welcome (see CONTRIBUTING.md). A new language appears in the account menu by itself.

## Fixed

- **Bandwidth by interface** puts IPv6 traffic, VPN clients and inbound connections under their interface
  instead of "none".

## Upgrading

Boxes on the beta channel see this version within 6 hours (System → Updates, or `apt-get update && apt-get
install goblin-gate` as root). The update also installs Caddy and iperf3, which are needed for the reverse
proxy and the throughput test. Updating needs no reboot. For Home Assistant, run
`apt-get install goblin-gate-plugin-homeassistant`, then enable it under System → Plugins.

## Try it without installing

```
docker run --rm -p 127.0.0.1:8090:8090 ghcr.io/mostlywithinspec/goblin-gate-demo
```

Then open http://localhost:8090.

## Install

Download `goblin-gate-0.2.0-beta.1-amd64.iso` below, boot it (BIOS or UEFI, Secure Boot works), pick the
disk, and open `https://<LAN address>` to run the setup wizard.
