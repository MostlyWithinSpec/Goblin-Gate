Goblin Gate 0.1.0, the first stable release.

It is the same code as 0.1.0-beta.10, which has run as a home firewall every day since it came out, plus the
switch to the stable channel. Everything that came in the betas is in: policies with security profiles,
intrusion prevention (Suricata, ET Open or ET Pro), web and DNS filtering, application control, threat feeds,
temporary blocks, IPv6 and multi-WAN, WireGuard and Tailscale, CAKE smart queue, dynamic DNS, UPnP, UPS
support, Goblin Checks, templates, dashboards and logs, packet capture, two-factor login, pfSense and
OPNsense import, plugins and Goblin Sentry, and the commit / confirm / roll back config model underneath it
all. The [README](https://github.com/MostlyWithinSpec/Goblin-Gate#readme) and the
[wiki](https://github.com/MostlyWithinSpec/Goblin-Gate/wiki) have the full tour.

## Update channels

- **stable is now the default.** A box that never picked a channel follows stable from this release on, and
  that includes boxes installed from a beta. Stable gets releases and their fixes.
- **beta** is opt-in: new features as soon as they are released, plus every stable release. To keep getting
  betas, pick **beta** under System → Updates and commit.
- The bridge for boxes on the old nightly channel is gone. A config that still names nightly follows beta,
  as before.
- The Updates page showed "stable" for a box with no channel picked while the box followed beta. Now they
  agree.

## Upgrading

Boxes on a beta see 0.1.0 within 6 hours. Update from System → Updates, or on the box as root:

```sh
apt-get update && apt-get install goblin-gate goblin-gate-plugin-sentry   # the plugin only if you use it
```

If the new version doesn't come back healthy within 5 minutes, the box reinstalls the previous one on its own.

## What's next

New features go to the beta channel first, as 0.2.0 betas: an OpenAPI description of the API, a built-in
throughput test, translations of the web UI, and more. Fixes for 0.1.0 come as 0.1.x on stable.
