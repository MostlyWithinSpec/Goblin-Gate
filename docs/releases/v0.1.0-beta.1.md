First beta of Goblin Gate. The feature set for 0.1.0 is complete: from here on the focus is fixing what you
find. **Keep your old firewall's config at hand while you switch, and report anything odd.**

## Highlights

- **Plugins.** Sandboxed plugins installed as packages (`goblin-gate-plugin-<name>`). Each runs as its own
  throwaway unprivileged user with no capabilities, a read-only system and caps of one CPU core and 512 MB. It
  can only use the API calls whose capabilities you approved under System → Plugins, and every call is audited.
  goblind knows a plugin by its systemd unit: there is no token to leak. A plugin can serve its own admin API to
  the web UI through goblind (JSON only, behind your login).
- **Goblin Sentry**, the first plugin (`apt install goblin-gate-plugin-sentry`): turns IPS alerts into incidents
  (repeats are grouped), adds what the box knows (direction, which of your hosts, by name, whether the address
  was seen or watched before) and answers with a small set of tools — temporary block, watch, notify, ignore,
  escalate — never a shell. Modes: off, shadow (record only), approve (the default: blocks wait for you) and auto.
  Nothing is blocked without your answer unless you clicked "Always do this" for that kind of alert, and your
  own hosts are never blocked. Every decision keeps a "why" record. Pages: Goblin SOC → approval queue,
  incidents, rules, blocks.
- **G.O.B.L.I.N.**, Sentry's local decision model: it learns from your own answers how you handle the incidents
  the rules would ask you about. It runs on the box, needs no GPU and no cloud, and never changes itself: each
  model is a numbered version with an evaluation report (accuracy per action, how often it would have ignored
  something you blocked), used only after you accept it, rolled back with one click. It never blocks on its own;
  set to "act", it may ignore, watch or notify above confidence thresholds you choose.
- **Temporary blocks.** Block an address in both directions for 1 minute to a week (Goblin SOC → Blocks, or the
  API). The kernel lifts the block on its own when it expires. The box itself, its gateways and DNS and NTP
  servers, the admin's own address, and (unless you allow it) your own networks can never be blocked.
- **pfSense import in the web UI** (System → Import), with the report from alpha.3's importer.

## Fixes

- The DNS and web filters now also stop Firefox's DNS-over-HTTPS and iCloud Private Relay on filtered networks,
  which bypassed them before. A filter profile that no policy uses shows a warning.
- Network → Gateways no longer shows a blank page.
- Revisions show their dates, and Rollback works.
- System → Updates, Notifications and Revisions are in the menu.
- The status badge in the header shows whether goblind answers; the activity button opens Log & Report.

## Upgrading from 0.1.0-alpha.3

alpha boxes follow the beta channel and see this version within 6 hours (or right away with
`GET /api/v1/system/updates?refresh=1`). Update from System → Updates, or on the box as root:
`apt-get update && apt-get install goblin-gate`. Then, if you want Sentry: `apt-get install goblin-gate-plugin-sentry`,
enable it under System → Plugins and approve the capabilities it asks for. Sentry needs IPS turned on to have
alerts to work with.

## Install

Download `goblin-gate-0.1.0-beta.1-amd64.iso` below, boot it (BIOS or UEFI, Secure Boot works), pick the
disk, and open `https://<LAN address>` to run the setup wizard.
