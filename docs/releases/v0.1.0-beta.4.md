Two-factor login, smart queue for a lag-free connection under load, dynamic DNS and network diagnostics.

## New

- **Two-factor login** (System → Administrators → Two-factor authentication): protect your account with a code from any
  authenticator app (Google Authenticator, Authy, 1Password, Bitwarden...). Each code works once. If you lose
  your phone, `goblin --set-password` on the console resets the password and turns two-factor off.
- **Active sessions** (System → Administrators): see where you are signed in and sign out other browsers.
- **Smart queue** (Network → Interfaces, on a WAN): CAKE traffic shaping in both directions keeps games and
  calls smooth while something else fills the line. Set the speeds to about 90 % of what your line really
  does. Takes effect on commit, no reboot.
- **Dynamic DNS** (Network → Dynamic DNS): keeps a hostname pointing at your public IP with Cloudflare,
  DuckDNS or any provider with an HTTPS update URL. Checked every 5 minutes; an "Update now" button pushes
  right away.
- **Diagnostics** (System → Diagnostics): ping, traceroute and DNS lookup run from the firewall itself, with a
  choice of source interface.
- **Wake-on-LAN** (Network → Devices): wake a device with one click.
- **DNS rebinding protection**, on by default: public names can no longer answer with private addresses, so a
  malicious website can't use your browser to reach devices on your network. Names you forward to your own
  DNS servers and your local domain are exempt; a checkbox on Network → DNS turns it off.

## Security

- Dynamic DNS tokens are hidden from read-only users and plugins like the other secrets, and are never shown
  in error messages.

See the [wiki](https://github.com/MostlyWithinSpec/Goblin-Gate/wiki) for setup details.

## Upgrading

Boxes on the beta channel see this version within 6 hours (System → Updates, or `apt-get update && apt-get
install goblin-gate goblin-gate-plugin-sentry` as root). Updating needs no reboot, and existing connections
stay up.

## Install

Download `goblin-gate-0.1.0-beta.4-amd64.iso` below, boot it (BIOS or UEFI, Secure Boot works), pick the
disk, and open `https://<LAN address>` to run the setup wizard.
