Third alpha of Goblin Gate. **This is still test software: try it in a VM or on a spare box first, and keep
your old firewall's config at hand.**

## Highlights

- **Import from pfSense.** System → Import takes a pfSense `config.xml` backup and turns it into a Goblin Gate
  candidate config: interfaces and VLANs, aliases, firewall rules, port forwards and outbound NAT, DHCP (ranges
  and static mappings), DNS resolver host and domain overrides, gateways, gateway groups and static routes,
  schedules, UPnP settings, time zone, NTP and DNS servers; pfBlockerNG and Suricata settings are mapped where
  there is an equivalent. If a pfSense interface does not match a port on this box, you pick it before the report.
  The report lists every item as converted, approximated or skipped, with the reason, and flags risky items
  (for example a port forward of every port). Nothing goes live until you review and commit.
  Passwords, certificates and private keys are never imported. CLI: `goblin import-pfsense config.xml --devices wan=eth0,lan=eth1`.
- **Multi-WAN and policy routing.** Gateways per WAN with health monitoring (ping loss and latency), gateway
  groups with tiers (failover) and weights (load sharing), a selectable default route, static routes, and a
  gateway per policy (route one VLAN through a second ISP or a VPN). Events `wan_down` / `wan_up` can be sent to
  your notification channels. Network → Gateways shows live status.
- **VPN providers.** WireGuard tunnels to providers such as Mullvad or Proton act as gateways, with an optional
  kill switch (traffic routed to the tunnel is dropped while it is down instead of leaking out the WAN).
- **Schedules.** Weekly time windows (Policy & Objects → Schedules) that a policy can be limited to, in the box's
  time zone, including overnight ranges; daylight-saving changes are handled.
- **UPnP / NAT-PMP / PCP** (Network → UPnP), off by default: pick the LAN interfaces, keep secure mode on, and
  optionally limit which clients may open which ports. Active mappings are listed live.
- **Updates page** (System → Updates): current and available version, release notes link, the channel, and an
  Update button with progress. A failed update still rolls itself back.
- **IPv6 in the web UI**: the IPv6 settings for interfaces and VLANs (DHCPv6 with prefix delegation, static,
  delegated, router advertisements) and IPv6 address objects.

## Fixes

- Outbound NAT (masquerade) now applies only to traffic leaving a WAN interface, not to traffic between LANs.

## Upgrading from 0.1.0-alpha.2

alpha.2 boxes follow the beta channel and see this version within 6 hours (or right away with
`GET /api/v1/system/updates?refresh=1`). Start the update with `POST /api/v1/system/updates/apply`, or on
the box as root: `apt-get update && apt-get install goblin-gate`. Reboot once afterwards if you plan to use
multi-WAN (a systemd-networkd setting it needs is read at boot).

From alpha.1, install the alpha.2 package first as described in the alpha.2 notes, then update as above.

## Install

Download `goblin-gate-0.1.0-alpha.3-amd64.iso` below, boot it (BIOS or UEFI, Secure Boot works), pick the
disk, and open `https://<LAN address>` to run the setup wizard.
