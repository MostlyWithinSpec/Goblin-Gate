Tools for seeing what is on your network and what the firewall does with it, plus security fixes. Updating
is recommended for everyone, above all if you have read-only admins or API tokens.

## Security

- **Read-only users and read-only API tokens could see secrets.** The config, the pending-changes diff
  and backups included the admins' password hashes, notification credentials (webhook URLs, bot tokens,
  SMTP passwords) and threat feed download headers. A read-only account could crack a hash offline and
  become an admin. These are now hidden from read-only users and plugins, and **backups are admins only**.
  If you have read-only admins or read-only tokens you don't fully trust, change the admin passwords and
  rotate those credentials after updating.
- **The Tailscale login link is admins only.** While Tailscale waited for a login, read-only users could see
  the link; whoever opens it adds the box to their own tailnet.
- **DHCP clients can no longer register `wpad`, `isatap`, `teredo`, `localhost` or the box's own name in
  DNS.** A device naming itself `wpad` could have become the proxy for browsers that auto-detect one.
- WireGuard endpoints are checked strictly (host:port for VPN providers, a DNS name or IP for your own
  server), so no stray characters reach the files they are written to.
- The web UI sends `X-Frame-Options`, `X-Content-Type-Options` and `Referrer-Policy` headers; SSH X11
  forwarding is off; restoring a crafted backup can no longer use unbounded memory; the web filter's
  "continue anyway" only returns to the warned site.

## New

- **Devices** (Network → Devices): everything on the network with IP, MAC, vendor, interface and last seen;
  give devices names that show up in logs and live traffic.
- **Policy simulator** (Policy & Objects → Simulate): which policy a connection would hit, without sending
  traffic. Denied connections in Log & Report have a "Why was this denied?" button.
- **Packet capture** (Log & Report → Packet capture): capture on any interface with filters, watch live,
  download a pcap for Wireshark.
- **Live traffic** (Log & Report → Live): top devices by bandwidth and their open connections.
- **Generated config** (System → Generated config): the files written for nftables, DHCP, DNS and IPS, with a
  diff of pending changes.
- **Snapshots** (System → Snapshots): save a named config, experiment, load it back. Included in backups.
- **Commit with automatic rollback** in the commit dialog: risky changes undo themselves unless you confirm.
- **Prometheus metrics** at `/metrics` (System → General → Metrics, off by default) and a Grafana dashboard
  in `docs/grafana/goblin-gate.json`.

## Fixes

- The DHCP page shows the active leases (it was always empty).
- Stop capture, Forget device and Unblock IP no longer show an error after they worked.

See the [wiki](https://github.com/MostlyWithinSpec/Goblin-Gate/wiki) for how to use the new tools.

## Upgrading

Boxes on the beta channel see this version within 6 hours (System → Updates, or `apt-get update && apt-get
install goblin-gate goblin-gate-plugin-sentry` as root). Updating needs no reboot, and existing connections
stay up.

## Install

Download `goblin-gate-0.1.0-beta.3-amd64.iso` below, boot it (BIOS or UEFI, Secure Boot works), pick the
disk, and open `https://<LAN address>` to run the setup wizard.
