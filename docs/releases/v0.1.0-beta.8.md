A hardening release: no new features, a tighter box. Recommended for everyone on the beta channel.

## Try it without installing

A demo image now comes with every release: Goblin Gate's web UI on a pretend home network, in one command.
Nothing in it is real and nothing leaves the container.

```
docker run --rm -p 127.0.0.1:8090:8090 ghcr.io/mostlywithinspec/goblin-gate-demo
```

Then open http://localhost:8090.

## Security

These come from a security review of a production Goblin Gate before 0.1.0. None of them was a way in;
each makes an attacker's job harder.

- **Login throttling** is stronger against clients that keep changing their address, and an admin who
  recently logged in from a device can't be kept out by someone else failing logins for that user.
- **Web UI headers:** a strict Content Security Policy and HSTS.
- **TLS:** TLS 1.2 now offers only modern, forward-secret cipher suites (TLS 1.3 is unchanged).
- **SSH:** port forwarding is limited to reaching the web UI on the box itself (`ssh -L` to the admin page
  still works).
- **Service sandboxes:** the firewall log collector and the UPS services (NUT) now run in systemd sandboxes
  like the DNS, DHCP and IPS services.

## Upgrading

Boxes on the beta channel see this version within 6 hours (System → Updates, or `apt-get update && apt-get
install goblin-gate goblin-gate-plugin-sentry` as root). Updating needs no reboot; the log collector
restarts once to enter its sandbox.

If you use SSH port forwarding to reach other hosts through the box, that no longer works: use WireGuard or
Tailscale for that.

## Install

Download `goblin-gate-0.1.0-beta.8-amd64.iso` below, boot it (BIOS or UEFI, Secure Boot works), pick the
disk, and open `https://<LAN address>` to run the setup wizard.
