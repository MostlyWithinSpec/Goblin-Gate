Goblin Gate 0.2.0, the second stable release.

It is the same code as 0.2.0-beta.1, which has run as a home firewall every day since it came out, plus one
fix for the reverse proxy. If you're coming from 0.1.0, this is what's new:

## New since 0.1.0

- **Reverse proxy** (Network → Reverse Proxy): publish web services from your network on public hostnames,
  such as `https://media.example.com` for your Jellyfin, with Let's Encrypt certificates that renew by
  themselves. One rule per hostname, no port forward per service. See the wiki page *Reverse Proxy*.
- **Home Assistant plugin** (`goblin-gate-plugin-homeassistant`): the gate shows up in Home Assistant through
  MQTT discovery, with WAN and gateway sensors, presence tracking for the devices you pick, and switches for
  the firewall policies you allow. Each switch is a commit you can see and roll back. See the wiki page
  *Home Assistant*.
- **Plugin secrets and policy switches:** plugins can ask for a password or token, stored like every other
  secret, and can get the capabilities `devices:read` and `policies:toggle`.
- **Throughput test** and **network card info** (Diagnostics): measure the speed between a computer and the
  box with iperf3, and see each interface's driver, link, queues and offloads, with warnings for the usual
  causes of a slow link.
- **Translatable web UI:** every page gets its text from one catalog, and each admin's language is stored on
  the box. English is the only language so far; translations are welcome (see CONTRIBUTING.md).
- **OpenAPI:** the API describes itself at `/api/v1/openapi.json`.

## Fixed

- **Reverse proxy on installed boxes:** in 0.2.0-beta.1 the proxy service failed to start on a box installed
  from the ISO, because it looked up its throwaway user by name and the ISO lacked the piece of systemd that
  resolves such names. It now takes the owner from its runtime directory, and the package depends on
  `libnss-systemd`.
- **Bandwidth by interface** puts IPv6 traffic, VPN clients and inbound connections under their interface
  instead of "none" (since 0.2.0-beta.1).

## Upgrading

Boxes on the stable or beta channel see 0.2.0 within 6 hours. Update from System → Updates, or on the box as
root:

```sh
apt-get update && apt-get install goblin-gate
```

The update also installs Caddy and iperf3, which the reverse proxy and the throughput test need. No reboot is
needed. If the new version doesn't come back healthy within 5 minutes, the box reinstalls the previous one on
its own. For Home Assistant, run `apt-get install goblin-gate-plugin-homeassistant`, then enable it under
System → Plugins.

## Install

Download `goblin-gate-0.2.0-amd64.iso` below, boot it (BIOS or UEFI, Secure Boot works), pick the disk, and
open `https://<LAN address>` to run the setup wizard.

## What's next

New features go to the beta channel first, as 0.3.0 betas: a plugin SDK, Proxmox and Docker awareness, an
internal certificate authority for the LAN, NetFlow and IPFIX export, and AppArmor confinement for the
services the gate runs. Fixes for 0.2.0 come as 0.2.x on stable.
