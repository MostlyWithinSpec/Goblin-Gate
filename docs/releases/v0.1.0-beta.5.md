Country rules, config history in git, log export, and a hardened Linux base underneath.

## New

- **Country rules (GeoIP)** (Network → Addresses, type *Country*): match traffic by country in policies and
  address groups, e.g. block a country from your LAN. The free [DB-IP](https://db-ip.com) Lite database (CC BY
  4.0) downloads the first time you use a country and refreshes monthly. If it can't be downloaded, the commit
  is refused rather than leaving country rules matching nothing.
- **Allowed sources on port forwards** (Network → Port Forwards): limit a forward to some addresses or
  countries, e.g. your Plex server only from home. Imported pfSense forwards keep their source restriction; a
  forward whose source can't be converted is skipped instead of being opened to everyone.
- **Config history in git** (System → Backup): every commit is pushed to your own GitHub or Gitea repository
  over SSH with a deploy key the box creates. Password hashes, two-factor secrets and tokens are left out. The
  server's host key is pinned on the first push, and a push never overwrites commits made elsewhere.
- **Log export** (Log & Report → Export): send traffic, IPS, DNS, web filter and system logs to a syslog
  server (UDP, TCP or TLS) or to Grafana Loki.
- **Automatic security updates**, on by default: Debian security fixes install nightly. Only the security
  archive installs on its own; Goblin Gate updates stay under your control (System → Updates, where the
  setting is too). A "Restart needed" badge shows when a kernel update waits for a reboot.

## Security

- **Anti-spoofing**: packets on the WAN that claim to come from your own networks, and packets on a LAN that
  don't belong to it, are dropped.
- **Sandboxed services**: the IPS no longer runs as root, and the DNS server, DHCP server, IPS and the
  firewall daemon run in systemd sandboxes (read-only system, only the capabilities they need).
- **Kernel and SSH settings**: ICMP redirects and source routing are off, kernel pointers are hidden from
  users, and SSH uses only modern MACs with agent forwarding off.
- Config history and log files are readable by root only.
- Credentials in a Loki URL are refused; they go in the username/password or token fields, which read-only
  users can't see.

See the [wiki](https://github.com/MostlyWithinSpec/Goblin-Gate/wiki) for setup details.

## Upgrading

Boxes on the beta channel see this version within 6 hours (System → Updates, or `apt-get update && apt-get
install goblin-gate goblin-gate-plugin-sentry` as root). Updating needs no reboot. DNS and DHCP restart once
to enter their sandboxes, which takes a second.

## Install

Download `goblin-gate-0.1.0-beta.5-amd64.iso` below, boot it (BIOS or UEFI, Secure Boot works), pick the
disk, and open `https://<LAN address>` to run the setup wizard.
