The last feature beta before 0.1.0: Goblin Checks, templates for common setups, UPS support, OPNsense import, ET Pro rules, and two update channels.

## New

- **Goblin Checks** (Goblin Checks in the menu, and a dashboard widget): an audit of your setup that lists
  what is risky or forgotten, most important first, each with a plain explanation and a link to the page
  that fixes it. Admin pages open on the internet, port forwards open to everyone (worse for SSH, RDP and
  databases), any-to-any policies from the WAN, admins without two-factor login, no config history off the
  box, security updates off, a pending restart and more. The score only counts real findings; dismiss the
  ones that are deliberate. See the [Goblin Checks](https://github.com/MostlyWithinSpec/Goblin-Gate/wiki/Goblin-Checks)
  wiki page for every check.
- **Templates** (Policy & Objects → Templates): a guest network, an IoT network, a port forward for some
  places only ("Plex only from home"), a network through a VPN provider with a kill switch, and a bedtime for
  the kids' devices. Answer a few questions, preview the changes, apply them to the candidate, commit.
- **UPS support** (System → UPS and a dashboard widget): a UPS on the box's USB port, or one a NAS or server
  already watches with NUT. Notifications when the power goes and comes back, and a clean shutdown when the
  battery runs low, at your own threshold if you like.
- **Import from OPNsense** (System → Import): the importer now reads OPNsense backups too, the older and the
  newer formats (firewall rules, aliases including GeoIP, outbound NAT, gateways, Kea or dnsmasq DHCP,
  Unbound). Password hashes, API keys, two-factor seeds, certificates, keys and alias credentials are never
  imported.
- **ET Pro rules** (Security → IPS): paste an ET Pro subscription code to use ET Pro instead of ET Open.

## Changed

- **Two update channels: stable and beta.** There is no nightly channel any more: every build in either
  channel has been through the full test run. Beta is the feature channel. A box that followed nightly now
  follows beta.
- pfSense import: disabled gateways and static routes are no longer imported as active, and manual
  outbound NAT rules are listed one by one in the report.

## Security

- A live event stream now ends when its API token is revoked or expires, its session ends, or its user is
  deleted. Before, an open stream kept receiving events.
- The UPS (NUT) configuration files, which hold its passwords, are readable only by root and NUT. Copies Goblin
  Gate keeps while applying a change are readable only by root.
- The generated-config viewer hides NUT passwords; the ET Pro code never appears in logs, errors or on a
  command line.

See the [wiki](https://github.com/MostlyWithinSpec/Goblin-Gate/wiki) for setup details.

## Upgrading

Boxes on the beta channel see this version within 6 hours (System → Updates, or `apt-get update && apt-get
install goblin-gate goblin-gate-plugin-sentry` as root). Updating needs no reboot. NUT (for UPS support) is
installed with the ISO; on an updated box, `apt-get install nut-client nut-server` adds it.

## Install

Download `goblin-gate-0.1.0-beta.7-amd64.iso` below, boot it (BIOS or UEFI, Secure Boot works), pick the
disk, and open `https://<LAN address>` to run the setup wizard.
