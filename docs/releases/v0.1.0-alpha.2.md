Second alpha of Goblin Gate. **This is test software: run it in a VM or on a spare box, not as your only firewall yet.**

## Highlights

- **Easy, safe updates.** Goblin Gate now updates from its own signed APT repository
  (`https://mostlywithinspec.github.io/Goblin-Gate/apt`, channels `stable`, `beta`, `nightly`). The box checks the
  channel every 6 hours and can notify you. An update runs in the background; if the new version does not come
  back healthy within 5 minutes, the box reinstalls the previous version on its own. API:
  `GET /api/v1/system/updates`, `POST /api/v1/system/updates/apply`. (The Updates page in the web UI comes next.)
- **IPv6.** WAN by DHCPv6 with prefix delegation (or static); LAN and VLANs get their own /64 from the
  delegated prefix (or a static one) with router advertisements (SLAAC). Address objects take IPv6 hosts,
  subnets and ranges; policies match IPv4, IPv6 or both. No IPv6 NAT. Settings are in the config/API for now;
  the web UI fields follow.
- **System page**: hostname, time zone, NTP and DNS servers, admins, API tokens, backup and restore, about.
- **Notifications page**: email, webhook, Discord, ntfy and Telegram channels and which events go where.
- The box's APT sources are now managed: Debian (with security updates and backports), Tailscale and Goblin Gate.

## Fixes

- Committing from the web UI works again: the Commit button and revision rollback were refused by the server
  and the error was hidden. Commit errors (for example a validation problem) are now shown in the dialog.
- The Review Changes dialog is centered on the screen in dark mode.
- Saving General settings on the System page no longer drops SSH keys or update settings.
- The installer no longer leaves an unusable `cdrom:` APT source behind.

## Upgrading from 0.1.0-alpha.1

alpha.1 has no updater yet, so this one upgrade is manual. On the box (console or SSH), as root:

```sh
cd /tmp
curl -fLO https://github.com/MostlyWithinSpec/Goblin-Gate/releases/download/v0.1.0-alpha.2/goblin-gate_0.1.0.alpha.2_amd64.deb
apt-get install ./goblin-gate_0.1.0.alpha.2_amd64.deb
```

goblind restarts, applies its config and writes the new APT sources; from then on updates come from the
repository (`apt-get update && apt-get install goblin-gate`, or the API above).

## Install

Download `goblin-gate-0.1.0-alpha.2-amd64.iso` below, boot it (BIOS or UEFI, Secure Boot works), pick the
disk, and open `https://<LAN address>` to run the setup wizard.
