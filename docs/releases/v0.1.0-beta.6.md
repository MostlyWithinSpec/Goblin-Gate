Power-user features: your own nftables rules, a CrowdSec bouncer, API tokens limited to what a script needs, a live event stream, global search, and a UI that works on a phone.

## New

- **Custom nftables rules** (Policy & Objects → Custom Rules): for the few things policies can't express, add
  your own nftables rules to the input, forward, output or NAT hooks, before or after the generated ones. Each
  rule is checked with `nft` before a commit, an error points at the rule that caused it, and every rule gets
  a hit counter. A warning on the page reminds you that a custom rule can lock you out; the usual
  commit/confirm rollback still applies.
- **CrowdSec bouncer** (Security → CrowdSec): point Goblin Gate at your CrowdSec instance (LAPI URL and a
  bouncer key from `cscli bouncers add goblin-gate`) and its ban decisions are dropped at the firewall, on the
  WAN only or on every interface. The page shows whether it is connected, how many decisions are active and
  how many packets were dropped.
- **Limited API tokens** (System → API Tokens): give a token only the scopes a script needs (read,
  write:firewall, write:network, write:system, actions, commit), an expiry date and the networks it may be
  used from. Presets for "Read only" and "Home automation" cover the common cases. Tokens with scopes can never
  see secrets.
- **Live events** (Log & Report → Live Events, and `GET /api/v1/events` as Server-Sent Events): commits,
  logins, rollbacks, WAN up/down, blocks and new devices as they happen. Read-only tokens can follow the stream
  too, e.g. from Home Assistant.
- **Global search** (Ctrl+K or the search button): jump to any page, policy, address, service, port forward,
  custom rule and more; object results open straight into their edit drawer.
- **Phone layout**: the menu becomes a slide-in drawer on small screens, the commit bar stays one tap away,
  wide tables scroll inside their box, edit drawers take the full width and forms stack to one column.

## Security

- A limited token can't read or write secrets: when it saves a section, stored secrets are kept only for
  entries it did not otherwise change.
- Custom rules may not use `flush`, `delete`, `table` or similar commands that would reach beyond the rule
  itself, and can't contain `;` or comments that hide a second statement.
- CrowdSec errors never include the bouncer key.

See the [wiki](https://github.com/MostlyWithinSpec/Goblin-Gate/wiki) for setup details.

## Upgrading

Boxes on the beta channel see this version within 6 hours (System → Updates, or `apt-get update && apt-get
install goblin-gate goblin-gate-plugin-sentry` as root). Updating needs no reboot.

## Install

Download `goblin-gate-0.1.0-beta.6-amd64.iso` below, boot it (BIOS or UEFI, Secure Boot works), pick the
disk, and open `https://<LAN address>` to run the setup wizard.
