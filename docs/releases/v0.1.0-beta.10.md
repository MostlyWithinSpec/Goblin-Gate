Fixes from the first days on beta.9, and a sweep through the whole web UI.

## Fixed

- **Bandwidth by interface** no longer shows old traffic under "none": traffic stored before beta.9 gets
  its interface filled in once when Goblin Gate starts, and a WAN that gets its address by DHCP is
  recognised too.
- **Goblin Checks** no longer says "Goblin Gate … is available" when only a plugin is behind; it names the
  plugin update instead. Dismissing "Restart needed" no longer hides every later restart, and the finding
  points to the account menu, where the restart is.
- **Tailscale settings** are loaded from your saved configuration. Before, the form reset every few seconds
  while you typed, and saving could blank Accept DNS, Login Server and Allow Access. A connected node shows
  as *Connected*.
- **NTP and DNS servers** (System → General): you can type a second server again (Enter and commas work).
- **Commit bar** says the commit was confirmed after you click Confirm, instead of "rolled back".
- **Blocking an address on your own network** (Devices, Sentry blocks): the "block anyway" checkbox now
  appears when it is needed.
- **Devices → Create address object** opens a new address filled in with the device's IP.
- **Failed saves** keep the form open with the error, instead of closing it and losing your edits.
- **Templates:** a day you picked can be unpicked. **Custom rules:** *Check* no longer leaves the rule in
  your pending changes.
- **WireGuard** peer configs download with their proper file name.
- Layout fixes on phones and small screens (Security, chart builder, packet capture, incidents and others),
  dark mode fixes for warning boxes and badges, and the theme button shows the current theme.

## Improved

- **SSH keys** (System → Admins): a proper, labelled field for the public key, with help on which file to
  paste and how to make one. A pasted private key or a key type that isn't supported is caught before
  saving, and the list shows each key's type and comment.
- Deleting admins, API tokens, SSH keys, DHCP servers, static routes and port forwards asks first.
- Errors that used to be swallowed are now shown: Tailscale, Dynamic DNS *Update now*, sign-out of
  sessions, CrowdSec, Sentry queue answers.
- The two-factor login step has a way back to username and password; packet capture can start a new
  capture; Dynamic DNS has *Update now*; the policy simulator opens matched policies directly.

## Upgrading

Boxes on the beta channel see this version within 6 hours (System → Updates, or `apt-get update && apt-get
install goblin-gate goblin-gate-plugin-sentry` as root). Updating needs no reboot.

## Try it without installing

```
docker run --rm -p 127.0.0.1:8090:8090 ghcr.io/mostlywithinspec/goblin-gate-demo
```

Then open http://localhost:8090.

## Install

Download `goblin-gate-0.1.0-beta.10-amd64.iso` below, boot it (BIOS or UEFI, Secure Boot works), pick the
disk, and open `https://<LAN address>` to run the setup wizard.
